# Azan App 🕌

A simple prayer times app that displays the five daily Islamic prayer times for any city, based on the date and country code entered by the user.

## ✨ Features
- 📅 Enter any date (DD-MM-YYYY) to get prayer times
- 🌍 Search by city name and country code
- 🕐 Displays all 5 daily prayers: Fajr, Dhuhr, Asr, Maghrib, and Isha
- ⏳ Shows the next upcoming prayer with a countdown (in Arabic)
- ✅ Visual timeline showing completed and upcoming prayers
- 🎨 Clean, warm-toned, and responsive UI

## 🛠️ Built With
- HTML5
- CSS3
- JavaScript
- Prayer Times API (Aladhan API)

## 🚀 How to Run
1. Clone this repository
2. Open index.html in your browser
3. Enter a date, city, and country code, then click Get Times
